# P1 真实样本：隔离验收数据

作用域：`SCOPE-P1-REAL-SAMPLE`；样本检查点：`CP-P1-REAL-SAMPLE`。

本目录保存 P1 三类真实样本的可追溯产物。它与正式 `SCOPE-0001` 数据隔离，不参与根目录 `ref.bib`、`ref.html` 或正式实体计数；此处的样本检查点不是正式 `CP-0001`。

样本包括 S18 DOI 期刊论文、S20 由权威报告记录标识且其标识列表未列 DOI 的技术报告，以及 S18 实际字节重放与 S17 作者排版文件/正式书目 Version 的区别。重复重放仅为验收操作，不是恢复出的历史 Upload。样本中有 3 个 Work、4 个 Version、3 个保留 Upload、2 条引用出现项、0 条 Assessment。

九个数据产物的完整 SHA-256 清单及 45 项通过结果见 [真实样本验收报告](../../p1-real-samples.json)。`checkpoint.json` 的内部清单只包含其余八个数据产物，自身最终字节哈希记录在外层验收报告中，避免自引用。目录中的 README 是隔离和恢复说明，不属于九个生成数据产物。

本目录只保留书目、作者及机构事实、自写中文摘要、书目引用、来源定位和校验信息；不保留 PDF、原始受限正文/摘要、API 凭据、私人路径或运行脚本。样本 HTML 用于验证文献落位与集合对账，不代表根目录文献索引的完整交互界面。

修正前的报告和检查点完整副本、原始失败记录及修复依据见 [修复历史](../../sample-repair-history/README.md)。不得将历史失配的报告作为当前有效产物清单。恢复时先核对验收报告中的九个文件哈希，再核对样本检查点内部八个依赖的哈希及其状态摘要。
